# Gestao de Tarefas

## Visao Geral

O modulo de **Gestao de Tarefas** permite criar, atribuir e acompanhar tarefas da equipe, garantindo que atividades sejam executadas dentro dos prazos.

## Funcionalidades Principais

### 1. Criar Tarefa

- **Titulo**: Nome da tarefa
- **Descricao**: Detalhes do que fazer
- **Responsavel**: Quem vai executar
- **Prazo**: Data limite

### 2. Acompanhar

- **Status**: Pendente, em andamento, concluida
- **Prioridade**: Baixa, media, alta, urgente
- **Progresso**: Percentual de conclusao

### 3. Organizar

- **Projetos**: Agrupar tarefas relacionadas
- **Tags**: Categorizar por tema
- **Filtros**: Buscar por criterios

## Como Usar

### Criar Nova Tarefa

1. Clique em "Nova Tarefa"
2. Informe o titulo
3. Descreva o que deve ser feito
4. Selecione o responsavel
5. Defina a prioridade
6. Configure o prazo
7. Salve a tarefa

### Atualizar Status

1. Acesse a tarefa
2. Altere o status conforme progresso
3. Adicione comentario se necessario
4. Atualize o percentual
5. Salve as alteracoes

### Visualizar Minhas Tarefas

1. Acesse "Minhas Tarefas"
2. Filtre por status ou prazo
3. Ordene por prioridade
4. Execute as mais urgentes primeiro

## Prioridades

- **Urgente**: Fazer imediatamente
- **Alta**: Fazer no dia
- **Media**: Fazer na semana
- **Baixa**: Fazer quando possivel

## Status

- **Pendente**: Aguardando inicio
- **Em Andamento**: Sendo executada
- **Aguardando**: Depende de algo/alguem
- **Concluida**: Finalizada
- **Cancelada**: Nao sera feita

## Dicas Operacionais

- **Clareza**: Descreva tarefas claramente
- **Divisao**: Quebre tarefas grandes
- **Prazo realista**: Considere imprevistos
- **Atualizacao**: Mantenha status atualizado

## Tratativas Comuns

### Tarefa Atrasada

1. Analise o motivo do atraso
2. Reprioritize se necessario
3. Renegocie prazo com solicitante
4. Solicite ajuda se precisar

### Tarefa Muito Grande

1. Divida em subtarefas
2. Defina marcos intermediarios
3. Acompanhe cada parte
4. Consolide ao final

### Responsavel Ausente

1. Verifique se pode aguardar retorno
2. Reatribua para outro colaborador
3. Comunique as partes interessadas
4. Atualize o registro da tarefa
