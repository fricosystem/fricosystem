# Perfil

## Visão Geral
A página **Perfil** é onde você gerencia suas informações pessoais, dados de acesso e preferências no APEX HUB. Cada usuário tem seu próprio espaço para personalizar como usa o sistema.

## Para Quem é Esta Página?
- Todos os usuários autenticados no APEX HUB

## O Que Você Encontra

### 1. Dados Pessoais
Informações básicas do seu perfil:
- **Nome completo**: Seu nome registrado no sistema
- **Email**: Email usado para login (não pode ser alterado sem autorização)
- **Telefone**: Seu número de contato
- **Cargo/Perfil**: Sua função na empresa
- **Departamento**: Seu setor/departamento
- **Unidade**: Qual filial você trabalha

### 2. Segurança e Acesso
Gerenciar como você acessa o sistema:
- **Alterar Senha**: Criar uma nova senha segura
- **Autenticação de Dois Fatores (2FA)**: Aumentar segurança
- **Histórico de Acesso**: Ver quando você fez login
- **Dispositivos Conectados**: Quais dispositivos acessaram sua conta
- **Desconectar de Todos**: Forçar logout em todos os dispositivos

### 3. Foto de Perfil
Sua imagem de identificação no sistema:
- **Enviar foto**: Adicionar ou atualizar sua foto
- **Remover foto**: Voltar ao avatar padrão
- **Formatos aceitos**: JPG, PNG (máximo 5MB)

### 4. Preferências e Configurações
Personalize sua experiência no APEX HUB:
- **Idioma**: Português (padrão), Inglês, Espanhol
- **Tema**: Claro ou Escuro
- **Fuso horário**: Seu local para exibir datas corretamente
- **Notificações**: Que tipo de mensagens você quer receber

### 5. Notificações
Controle como ser notificado:
- **Email**: Receber avisos por email
- **Notificações do sistema**: Pop-ups dentro do APEX HUB
- **SMS**: Mensagens curtas (se configurado)
- **Frequência**: Com que frequência receber alertas

Tipos de notificação:
- Requisições atribuídas
- Manutenção vencida
- Ordens de serviço abertas
- Alertas de estoque baixo
- Aprovações pendentes

### 6. Assinatura Digital
Se sua empresa usa assinatura digital:
- **Certificado**: Carregar certificado digital
- **Validade**: Data de expiração
- **Status**: Se está válido

## Como Usar

### Atualizar Dados Pessoais
1. Acesse **Perfil** no menu (geralmente no canto superior direito)
2. Clique em **Editar Perfil**
3. Altere os campos desejados
4. Clique em **Salvar**
5. Você receberá uma confirmação

### Alterar Senha
1. Acesse **Perfil** → **Segurança**
2. Clique em **Alterar Senha**
3. Digite sua senha atual
4. Digite a nova senha (mínimo 8 caracteres)
5. Confirme a nova senha
6. Clique em **Salvar**

### Ativar Autenticação de Dois Fatores (2FA)
1. Acesse **Perfil** → **Segurança**
2. Clique em **Ativar 2FA**
3. Escolha entre:
   - **Aplicativo**: Google Authenticator, Authy, etc.
   - **SMS**: Código enviado por mensagem
4. Siga as instruções
5. Guarde os códigos de recuperação em local seguro

### Atualizar Foto de Perfil
1. Acesse **Perfil** → **Foto**
2. Clique em **Enviar Foto**
3. Selecione uma imagem do seu computador/celular
4. Ajuste o enquadramento se necessário
5. Clique em **Confirmar**

### Ver Histórico de Acesso
1. Acesse **Perfil** → **Segurança**
2. Veja a seção **Histórico de Acesso**
3. Mostra data, hora, local aproximado e dispositivo
4. Se identificar acesso não autorizado, mude a senha imediatamente

### Desconectar de Todos os Dispositivos
1. Acesse **Perfil** → **Dispositivos Conectados**
2. Veja lista de dispositivos conectados
3. Clique em **Desconectar de Todos**
4. **Atenção**: Você será desconectado do dispositivo atual também
5. Faça login novamente para reconectar

### Gerenciar Notificações
1. Acesse **Perfil** → **Notificações**
2. Ative/desative os tipos de notificação desejados
3. Configure a frequência (imediato, diário, semanal)
4. Clique em **Salvar**

## Dicas de Segurança
- **Senha forte**: Use letra maiúscula, minúscula, número e símbolo
- **2FA**: Sempre ative autenticação de dois fatores
- **Senha única**: Não reutilize senhas de outros sites
- **Alerta**: Se notar atividades estranhas, mude a senha
- **Foto**: Mantenha uma foto profissional para fácil identificação

## Próximos Passos

- Se você esqueceu a senha: Clique em "Esqueci a Senha" na tela de login
- Para suporte: Entre em contato com seu supervisor
