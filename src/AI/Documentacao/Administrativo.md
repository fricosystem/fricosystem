# Administrativo

## Visão Geral
A página **Administrativo** é o centro de controle para supervisores e administradores do APEX HUB. Aqui você encontra todas as ferramentas necessárias para gerenciar usuários, perfis, configurações do sistema e dados mestres da organização.

## Para Quem é Esta Página?
- Administradores do sistema
- Supervisores
- Gerentes que precisam gerenciar usuários e permissões

## Áreas Principais

### 1. Gestão de Usuários (/gestao-usuarios)
Gerenciar todos os usuários cadastrados no sistema:
- **Criar novo usuário**: Adicionar funcionários ao sistema
- **Editar usuário**: Atualizar dados, email, telefone
- **Ativar/Desativar**: Controlar acesso ao sistema
- **Resetar senha**: Ajudar usuários com acesso perdido
- **Filtrar por departamento**: Ver usuários por setor/unidade

**Principais campos:**
- Nome completo
- Email (usado para login)
- Cargo/Perfil
- Departamento/Setor
- Status (Ativo/Inativo)

### 2. Gestão de Perfis (/gestao-perfis)
Criar e configurar os tipos de perfil do sistema:
- **OPERADOR**: Acesso básico ao estoque e requisições
- **TÉCNICO**: Acesso a manutenção e equipamentos
- **SUPERVISOR**: Acesso completo ao seu departamento
- **ADMINISTRADOR**: Acesso total ao sistema

Cada perfil tem permissões diferentes em cada página.

### 3. Gestão de Produtos (/gestao-produtos)
Gerenciar o catálogo principal de produtos:
- Criar produtos
- Editar informações (nome, código, preço)
- Definir fornecedores
- Configurar quantidades mínimas e máximas
- Ativar/Desativar produtos
- Importar produtos em lote

### 4. Unidades/Filiais (/unidades)
Cadastrar e gerenciar unidades da empresa:
- Adicionar filiais
- Configurar endereços
- Atribuir responsáveis
- Definir cobertura de estoque
- Horários de funcionamento

### 5. Gestão de Fornecedores (/gestao-fornecedores)
Gerenciar base de fornecedores:
- Cadastrar novos fornecedores
- Editar dados de contato
- Configurar condições de pagamento
- Definir prazos de entrega
- Controlar qual fornecedor fornece qual produto

### 6. Setores (/setores)
Organizar a estrutura de departamentos:
- Criar/editar setores
- Atribuir responsáveis
- Definir equipes de trabalho
- Agrupar máquinas por setor

### 7. Centro de Custo (/centro-custo)
Gerenciar alocação de despesas:
- Criar centros de custo
- Atribuir departamentos
- Rastrear gastos por centro
- Gerar relatórios de gastos

### 8. Gestão de Manutenção (/gestao-manutencao)
Configurar estrutura de manutenção:
- Definir tipos de manutenção
- Criar planos preventivos
- Atribuir técnicos
- Configurar frequências

## Como Usar - Fluxo Típico

### Primeira Vez no Sistema
1. Acesse **Gestão de Usuários** → Crie os usuários da empresa
2. Acesse **Gestão de Perfis** → Configure os perfis necessários
3. Acesse **Gestão de Produtos** → Importe ou crie produtos
4. Acesse **Unidades** → Cadastre filiais
5. Acesse **Fornecedores** → Adicione fornecedores

### Dia a Dia
1. Verifique novos usuários pendentes de aprovação
2. Atualize dados mestres conforme necessário
3. Ative/desative usuários
4. Ajuste permissões conforme mudanças organizacionais

## Dicas de Segurança
- **Cuidado com permissões**: Verifique permissões antes de ativar usuários
- **Backup regular**: Exporte dados críticos periodicamente
- **Auditoria**: Revise logs de acesso ao APEX HUB
- **Senhas**: Force reset de senhas para novos usuários

## Próximos Passos
- Após configurar os dados mestres, os usuários podem começar a usar o sistema normalmente
- Retorne aqui periodicamente para manutenção de dados
- Use os relatórios administrativos para acompanhar saúde do sistema

## Atalho Rápido
Acesse via menu lateral: **Administrativo** → Escolha a opção desejada
