# Bem-vindo ao APEX HUB

## Visão Geral
A página **Bem-vindo** é a primeira página que você vê quando inicia sua sessão no APEX HUB. Esta página exibe um acolhimento personalizado com informações sobre seu perfil e atalhos rápidos para as funções principais do sistema.

## Para Quem é Esta Página?
- Novos usuários do sistema
- Usuários em primeira acesso (quando não estão aprovados)
- Todos os perfis (OPERADOR, TÉCNICO, SUPERVISOR, etc.)

## O Que Você Encontra Aqui

### 1. Saudação Personalizada
No topo da página, você verá uma mensagem de boas-vindas com:
- Seu nome completo
- Seu perfil/cargo no sistema
- A data e hora atual

### 2. Status de Aprovação
Se você é um novo usuário, verá informações sobre:
- Seu status de aprovação
- Quando será analisada sua solicitação
- Contato do supervisor responsável

### 3. Atalhos Rápidos (Dashboard Cards)
Cartões coloridos que dão acesso direto às principais funcionalidades:
- **Produtos**: Acessar o estoque e gerenciamento de produtos
- **Requisições**: Criar e acompanhar requisições de material
- **Manutenção**: Ver equipamentos e agendar manutenção preventiva
- **Ordens de Serviço**: Consultar chamados e reparos
- **Relatórios**: Gerar relatórios de produção e estoque

### 4. Notificações e Alertas
Se houver:
- Tarefas pendentes atribuídas a você
- Ordens de serviço abertas
- Manutenção vencida
- Requisições aguardando aprovação

## Como Usar

### Para Acessar uma Função
1. Clique em um dos cards com a função desejada
2. Você será redirecionado para aquela página
3. Comece a trabalhar normalmente

### Se Você é um Novo Usuário
1. Veja seu status na caixa "Status de Aprovação"
2. Aguarde a aprovação do supervisor
3. Após aprovado, você será redirecionado para o Dashboard principal

## Dicas Úteis
- Esta página muda conforme seu perfil no sistema
- Os atalhos são personalizados de acordo com seu cargo
- Volte aqui sempre que precisar de um atalho rápido para as principais funções

## Próximos Passos
Após a aprovação, você terá acesso completo ao sistema. Explore o menu lateral para conhecer todas as funcionalidades disponíveis para seu perfil.
