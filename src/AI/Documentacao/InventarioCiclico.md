# Inventario Ciclico

## Visao Geral

O modulo de **Inventario Ciclico** permite realizar contagens parciais e programadas do estoque, focando em grupos especificos de produtos ao inves de contar todo o estoque de uma vez.

## Funcionalidades Principais

### 1. Criar Ciclo de Contagem

- **Selecionar criterios**: Escolha produtos por categoria, deposito, prateleira, valor ou frequencia de movimentacao
- **Definir responsavel**: Atribua um colaborador para realizar a contagem
- **Agendar data**: Defina quando a contagem deve ser realizada

### 2. Executar Contagem

- **Lista de itens**: Visualize os produtos que devem ser contados
- **Registrar quantidades**: Informe a quantidade fisica encontrada
- **Anotar divergencias**: Registre observacoes sobre diferencas encontradas

### 3. Analisar Resultados

- **Comparativo**: Veja a diferenca entre estoque sistema x fisico
- **Acuracia**: Acompanhe o percentual de precisao do estoque
- **Historico**: Consulte contagens anteriores

## Como Usar

### Iniciar um Novo Ciclo

1. Clique em "Novo Ciclo"
2. Selecione os criterios de agrupamento (ex: produtos da prateleira A)
3. Defina o responsavel pela contagem
4. Confirme a criacao do ciclo

### Realizar a Contagem

1. Acesse o ciclo ativo
2. Para cada produto, informe a quantidade encontrada fisicamente
3. Se houver divergencia, adicione uma observacao
4. Clique em "Finalizar Contagem"

### Ajustar Divergencias

1. Apos finalizar, analise as divergencias
2. Decida se deve ajustar o estoque no sistema
3. Solicite aprovacao do supervisor se necessario
4. Confirme os ajustes

## Dicas Operacionais

- **Frequencia**: Produtos de alto giro devem ser contados com mais frequencia
- **Horario**: Realize contagens em horarios de baixa movimentacao
- **Organizacao**: Mantenha os produtos bem organizados para facilitar a contagem
- **Documentacao**: Sempre registre observacoes sobre divergencias

## Tratativas Comuns

### Divergencia de Quantidade

1. Verifique se houve movimentacao nao registrada
2. Confira se o produto nao esta em outro local
3. Revise lancamentos recentes de entrada/saida
4. Se persistir, ajuste o estoque com justificativa

### Produto Nao Encontrado

1. Confirme o codigo e descricao do produto
2. Verifique outros depositos/prateleiras
3. Consulte movimentacoes recentes
4. Registre como "nao localizado" se necessario

### Produto em Local Errado

1. Registre a localizacao correta encontrada
2. Atualize o enderecamento do produto
3. Informe ao responsavel pelo almoxarifado
